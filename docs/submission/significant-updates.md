# Significant updates built for this hackathon

- Defined the hackathon MVP around Prevent, Manual Diagnose, and Auto Heal.
- Created four frozen v1 contracts for hardware model, telemetry, tools, and lifecycle events.
- Added a portable JSON Hardware-as-Code profile with validation and firmware code generation.
- Built ESP32-S3 telemetry, INA226 identity/signal checks, PS2 fail-safe control, three encoder
  channels, dual L298N support, and supervised command firmware.
- Built persistent FastAPI ingestion, serial logging, WebSockets, grounded context, Nebius/Nemotron
  provider integration, bounded orchestration, policy, verification, evaluation, and audit trails.
- Built the React dashboard, scalable hardware/wiring explorer, readable live log, three-wheel
  monitor, AI Doctor, diagnosis timeline, Manual/Auto Treatment UI, reconnect/retry handling, and
  evidence export.
- Added unit, contract, firmware, load, evaluation, physical acceptance, recovery, Docker, and CI
  gates plus the final submission pack.

Pre-existing generic tools and open-source dependencies are listed by their licenses and are not
claimed as newly authored project features.
