# NeXus three-wheel wiring — final v6

This pack is the human-readable companion to:

- `nexus-hardware/profiles/nexus-profile-goouuu-esp32-s3-ina226-dual-l298n-3wheel-ps2-v1.json`
- firmware environment `nexus-goouuu-esp32-s3-3wheel-ps2`

Configuration: GOOUUU ESP32-S3-N16R8, existing INA226 R100, two L298N modules,
three JGB37-520 Hall-encoder motors, PS2 receiver, 3S LiPo, fuse, relay, maintained
ON/OFF switch, NC E-stop, 5 V buck, PCT distribution blocks. BNO055, BME680 and
buzzer are deliberately excluded.
